# Greytone Digital: development standards

Permanent standards for every public-facing website or digital product
Greytone builds, for Greytone or for clients. They apply automatically;
no one has to request them.

| File | Use |
|---|---|
| `GREYTONE-LAUNCH-STANDARD.md` | The mandatory standard: technical SEO, search-engine readiness, AI-search readiness, Search Console/Bing, pre-launch testing, final checklist, private-app rules, privacy baseline |
| `LAUNCH-CHECKLIST.md` | Pre-launch checklist and client launch report, with client handoff steps |
| `templates/CLAUDE.md` | Drop-in instructions for every new project repo (Claude reads it automatically) |
| `templates/public-site/` | robots.txt, sitemap.xml, head tags and JSON-LD starters for public sites |
| `templates/private-app/` | robots.txt, Netlify `_headers` and meta tag that keep private apps out of search |

**New project kickoff:** copy `templates/CLAUDE.md` (fill in Project Facts),
`LAUNCH-CHECKLIST.md`, and the matching starter folder into the new repo.

This folder is documentation. It is never uploaded to greytonedigital.com.
